How to Import
  1. Click Download Template (top right) to get the Excel file with all column headers.
  2. Fill in your staff data. Columns marked in red are required; teal columns are optional.
  3. Save the file and upload it below.
  4. The system will create an account for each valid row, issue a contract, and send a welcome notification.
Each employee's default password is Micei2021. They must change it on first login. Department names must exactly match existing departments in the system.
