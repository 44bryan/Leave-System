How to Restore

If you ever need to restore the system from a backup, follow these steps via SSH on the VPS:

# 1. Restore database (replace TIMESTAMP with the backup name)
PGPASSWORD="HrmDb2024!" pg_restore -U hrmuser -h localhost -d hrmdb \
  --clean --if-exists /root/backups/FOLDER/database_TIMESTAMP.dump

# 2. Restore media files
tar -xzf /root/backups/FOLDER/media_TIMESTAMP.tar.gz -C /var/www/hrm/

# 3. Restart the application
systemctl restart hrm
