MICEI HRM — Email Notification Setup Guide

This guide explains how to fully enable email notifications for all staff on the MICEI HRM system deployed on Railway.

Overview

MICEI HRM uses Resend (resend.com) to send email notifications. Resend requires a verified domain to send emails to any recipient (Gmail, iCloud, Outlook, etc.).

Setup Steps

Step 1 — Buy a Domain Go to namecheap.com and purchase a domain. Recommended options:
  • micei-hr.com
  • micei-micei-hrm.com
  • Or use an existing institution domain if one already exists
Cost: approximately $10–15/year.
Step 2 — Add the Domain in Resend
  1. Log in at resend.com
  2. Go to Domains → click Add Domain
  3. Enter your domain name and select your region
  4. Resend will display DNS records (MX, TXT, CNAME)
Step 3 — Add DNS Records in Namecheap
  1. Log in to namecheap.com
  2. Go to Domain List → click Manage next to your domain
  3. Click Advanced DNS
  4. Add each DNS record that Resend provided (Type, Host, Value)
  5. Save all records
DNS propagation can take a few minutes up to 24 hours.
Step 4 — Verify Domain in Resend
  1. Go back to Resend → Domains
  2. Click Verify DNS Records
  3. Status should turn green: Verified
Step 5 — Update Railway Environment Variables
  1. Log in to railway.app
  2. Open your MICEI HRM project → go to Variables
  3. Set the following variables:
VariableValue
DEFAULT_FROM_EMAILMICEI HRM <noreply@yourdomain.com>
EMAIL_NOTIFICATIONS_ENABLEDTrue
RESEND_API_KEYYour Resend API key (from resend.com/api-keys)
SITE_URLhttps://micei-hr.up.railway.app
Railway will automatically redeploy after saving variables.
Note: Once done, emails will be delivered to all inboxes — Gmail, iCloud, Outlook, Yahoo, etc. — without any action required from staff.
